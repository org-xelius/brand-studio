# Brand Studio

**Version 1.0.0.** A local DeepSeek Harness panel for company brands, campaigns, weekly planning and guided social design. It keeps the Harness interface quiet — native typography, light/dark surfaces, restrained blue actions — and puts the work in the poster: ten arrangement icons that redraw the canvas, six bundled font pairings, literal image opacity and true poster-width actions.

Everything composes locally. Text is real text, never AI lettering; original products and logos keep their pixels; nothing is published automatically.

## Open it

Select **Brand Studio** in the Harness sidebar and refresh the existing Harness page. This is an installed plugin, not a separate server.

## Make a design

1. Add a company (name, description) and confirm the planning time zone.
2. Set **Brand colours** — primary, accent, ink and paper. They colour the artwork only.
3. Create a campaign, or start a one-off design.
4. In the editor, write the exact words, then open **Look** and click an arrangement icon.
5. Choose the output format, wait for the preview and autosave, tick the review checkbox, **Save & review this version**, then **Export reviewed PNG**.

Composition, typography and format changes never call an image provider. Only **Image setup → Generate** does, and that needs your own OpenAI Images API key plus an explicit confirmation of the paid request.

## Ten arrangements

| Arrangement | Structure |
| --- | --- |
| Bold backdrop | Full photographic or solid field with monumental type |
| Subject right | Left reading column, separate right-hand image |
| Image lead | Dominant complete image above supporting copy |
| Centered announcement | Short centered statement with a compact action |
| Service sheet | Detailed information in an editorial reading column |
| Subject left | Mirror of Subject right |
| Image footer | Copy first, substantial lower image field |
| Framed focus | Contained central image between headline and copy |
| Type-led | Headline dominates; small image accent |
| Offset grid | Upper headline, asymmetric lower image/copy split |

Icons describe the format you are viewing. Clicking a different icon applies that arrangement immediately as one undo step; clicking the active one keeps your manual tweaks. Selection resets template-owned text sizing and placements but preserves words, images, opacity, colours and font pairing.

## Six font pairings

| Pairing | Headline / supporting text |
| --- | --- |
| Bold studio | League Spartan / Source Sans 3 |
| Compact impact | Barlow Condensed / Source Sans 3 |
| Clean digital | Archivo / Manrope |
| Editorial serif | Lora / Source Sans 3 |
| Geometric modern | Space Grotesk / DM Sans |
| Tall editorial | Oswald / Manrope |

All faces are bundled SIL OFL 1.1 files — selecting a pairing never downloads anything. Per-role family, weight, size, leading and tracking remain editable under **Advanced typography**.

## Images and opacity

Choose a backdrop, subject or product/screenshot and upload or reuse a company asset. **Background source** switches between solid colour and image; the opacity control is literal (`0%` hides, `100%` keeps full strength). Image selection is shared across formats, while opacity and positioning can differ per format. Product/screenshot pixels are always contained, and **Framed focus** fits the complete background rather than cropping it.

## Review and export

Review binds one exact format and bitmap. Any later edit invalidates it. Exports are native-resolution PNGs: 1080×1080, 1080×1350, 1080×1920 and 1200×628.

Saved versions keep their words, colours, fonts, assets and layout. Older designs open in their original rendering and are never migrated silently; choosing an arrangement is an explicit, undoable upgrade of the editable draft.

## Limits

- No auto-publishing or social scheduling.
- No automatic background removal, no arbitrary font upload by URL, Latin font subsets only.
- Text never shrinks silently: overflow blocks review and asks you to edit or change arrangement.
- Screen-reader behaviour, native OS colour popovers and real browser zoom beyond the checked cases are not certified.
