## Host truth, not invented theme conventions
Read `.dsh-reference/dsh/node_modules/@deepseek-ai/dsh-client-ui-theme/{README.md,lib/client.js}` and layout/practices as useful.
- `var(--dsw-font-family)` is ordinary UI family. Do NOT use `--dsw-font-family-brand` Montserrat. Native fallback: -apple-system,BlinkMacSystemFont,"Segoe UI","PingFang SC","Hiragino Sans GB","Microsoft YaHei","Helvetica Neue",Helvetica,Arial,sans-serif.
- Current interface font token `--dsw-font-s-14` =40014px/22px, strong500; xs13/20, xxs12/18, xxxs11/14; base16/24; l20/28; xl24/32. Variables have decomposed -font-family/-font-size/-font-weight/-line-height forms. `--dsh-content-font-size` is conversation size, not universal interface size.
- Authoritative `body[data-ds-dark-theme]` dark, absence light WITH `html[data-ds-theme-source]`. Host resolves system using matchMedia; do not override a host-fixed light with OS dark. Token changes are live CSS; no new theme injection needed. Standalone only: html:not([data-ds-theme-source]) may use prefers-color-scheme.
- Inherit `--dsw-alias-bg-base`(#fff/#151517), bg-layer-1(#fff/#232324), bg-layer-2(#fff/#2c2c2e), bg-module-platform(#f5f6f7/#353638), label-primary(#0f1115/#f9fafb), label-secondary(#61666b/#cfd3d6), label-tertiary(#81858c/#adb2b8), border-l1(#0000000a/#ffffff0f), border-l2(#0000001a/#ffffff1f), border-l3(#0000001f/#ffffff29), border-l4(#00000029/#ffffff33), state-business-primary(#4176e6/#7aaaff), interactive-bg-hover(#2631480f/#ffffff14). Verify exact token spelling in source before relying on these. Scope our semantic --bs-* aliases to `.bs` and dialog descendants. Dialogs inherit actual font and dark native colour-scheme too.
- Focus --dsw-focus-ring-width2px, colour --dsw-focus-ring-color falling back business-primary. Preserve --dsh-frame-top-clearance48px native mac, no fake app window.
- Don't import/require host ui-primitives: shipped practice says prefixed own React controls with inherited --dsw-alias-* tokens.
