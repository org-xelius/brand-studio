# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Harness-compatible ESM Host plug-in, React client module, esbuild. User approved recommended build/test dependencies. Existing Harness services own connection, credentials, and persistent storage.

## Users
Non-technical business owners and marketers managing social designs for several companies and simultaneous campaigns.

## Product Purpose
Turn ordinary business intent into useful on-brand social images, with reusable weekly campaign planning and reliable local text/logo composition.

## Operating Context
An installed panel inside the existing Harness GUI, not a separate server. Company → Campaign → Weekly plan → Post → Versions. Preserve one-off creation. User approved the detailed workspace build prompt and requested a usable first build to iterate.

## Capabilities and Constraints
Persistent companies, campaigns, weekly plans, image generation, local composition/export. Explicit confirmation before paid generation. API-key image authentication is distinct from chat OAuth. No automatic publishing, recurring paid calls, or schedules. Exact implemented scope and missing items must be documented honestly.

## Brand Commitments
Brand Studio name; intuitive guided left panel with large result preview; calm accessible interface consistent with the host. Poster outputs use company palette and licensed typography, independently of the Harness interface font and accent used by the editor shell. Supplied agency-poster references establish the target craft; the proof set has no original customer logo or real website screenshot, so those must never be fabricated or presented as supplied assets. Never seed real-sounding customer claims or generated API results.

## Product Principles
Guide rather than demand prompting. Keep original company assets separate from generated images. Never invent offers or claims. Save drafts by context. Separate planning from spending.

## Accessibility & Inclusion
Keyboard-accessible forms, labelled inputs, visible focus, non-colour statuses, responsive layout, contrast, and usable zoom.
