# Brand Studio 0.5 — flexible composition

As built on 11 November 2026. This extends the native Harness workspace; it does not replace the application shell or start another server.

## What changed

- **Transparent text layers.** Brand name, headline, body, kicker and supplied annotation use fill-only glyphs directly over the composite: no rectangular backing plates, glyph halos, text shadows or photo-exclusion holes. Original uploaded logo pixels remain untouched; an opaque background baked into an image is not removed.
- **Six independent CTA treatments:** full strip, rectangle, rounded, pill, outline and text-only. Palette/custom-hex fill and text colours, fit/full width, alignment, padding and arrow are editable. Choosing a style starts strip at full width and the others at content fit; width remains independently editable. Whitespace-only CTA copy paints nothing. Long copy wraps or blocks review, never silently vanishes behind a bar.
- **Eight trusted editable SVG motifs:** ribbon, orbit, proof marks, responsive frames, answer exchange, research folio, decision junction and interface modules. Opacity is literal 0–100%; colour, position, scale and rotation are separate. Download the selected recoloured SVG for external editing. Arbitrary SVG uploads remain disallowed.
- **Six arrangements:** lateral, broadside, specimen, centered, spread and cover. Each has independently authored square, portrait, story and landscape geometry. Lateral/centered/spread flow the measured headline, body and CTA together. No explicit font size is silently reduced.
- **Optional company design languages.** Creative modular proposes lateral/broadside/specimen with creative motifs; Research editorial proposes centered/spread/cover with research/system motifs. Both are editable proposals, not new brand rules. Existing company colours and typography remain separate settings. Opt-in variation allocates choices once when a post is created, atomically for one-off and weekly planning. Opening, editing, changing ratio or reopening a plan does not reroll it. Pinned campaign looks take precedence.
- **Explicit current-draft application.** Preview a company language on the actual canvas before applying it. Format-only application preserves the base and other ratios. All-format application replaces arrangement/motif/CTA overrides while retaining type/image fine-tuning. A new review is required; undo and saved history remain available.

## Compatibility and safeguards

Poster schema remains version 3. Only explicit `compilerVersion:3` selects flexible composition. Missing selectors and explicit compiler2 continue through their frozen kernels; old options acquire no new defaults. New unsupplied posts use compiler3. Inherited company/campaign templates are copied into new posts without rewriting the stored templates. Directly supplied old posters remain explicit old posters.

Existing drafts expose **Look → Use new design tools**; saved scenes are never upgraded in place. Copying a saved compiler3 version does not downgrade it. Flexible arrangements own alignment and keep essential copy in front; old variation, emphasis/underline, text-depth and foreground-shadow decorations are not used by this compiler and are not exposed as inert controls. The old compiler2 tools remain available for old drafts.

Company profiles live outside `brandKit`. Omitted profiles stay omitted; an explicit null command removes one. Changing only a future profile preserves backend current-review/export eligibility and does not repaint the mounted approved bitmap. Saving company settings currently returns Home/unmounts the editor, so frontend approval retention across navigation is **not** promised. Profile/cursor state is not consulted during rendering; concrete choices and provenance are frozen into each post.

The renderer measures contrast against actual composited pixels inside opaque glyph interiors, chooses ink/paper using that same metric and blocks a role below 4.5:1 with recovery guidance. It never restores a backing plate. This technical check is not WCAG certification or a substitute for human review. All existing font ownership, exact face/digest/cmap, asset ownership, overflow, original-containment and asynchronous staging protections remain. A reviewed export downloads the exact captured PNG Blob/digest; its receipt is client-computed, not server retention or server pixel verification.
