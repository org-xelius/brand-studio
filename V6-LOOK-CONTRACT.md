## Options and functions
`template-model.js` exports:
- `TEMPLATES`: id/label/description/version, labels Bold backdrop, Subject right, Image lead, Centered announcement, Service sheet.
- `TEMPLATE_DEFAULTS`: complete composition/motif/cta/textColors/layers template4 groups. Layers background includes mode `solid|image`, opacity0..1, blur0..24; foreground adds opacity0..1 to old x/y/scale/rotation/shadow; product:{opacity:1}. Defaults background solid/opacity1. Motif only none (retain other legacy motif fields if necessary, reject non-none in4). CTA width `fit|column|poster`, rest six styles/colour controls identical to3. Default bold-backdrop CTA strip/poster/ink fill/auto text. No hidden tonal surface or motif rendering in4.
- `normalizeTemplateGroup(group,value,partial=false)` (or equivalent strict validation helpers used in poster-model).
- `upgradePosterTemplate(options,hasBackground=false)`: concrete compiler4 complete normalized options; preserve words external, fonts, colours, opacity, asset refs external; map legacy layouts (`lateral` subject-right, `broadside/cover` bold-backdrop, `specimen` image-lead, `centered` centered-announcement, `spread` service-sheet); old recipe editorial => solid; otherwise image when hasBackground; force motif none and details.surface flat. No old default changes.
- `applyTemplate(poster,id,format='square',allFormats=false,hasBackground=false)`: one deterministic transformation used by actual UI and thumbnails. Upgrade if needed. Template selection resets role sizes/lineHeight to null, scale1 and layout-owned CTA geometry/width to appropriate template default; keep fontIDs/weights/tracking, CTA colours/words, images and existing opacity. Clear corresponding inherited overrides when applying all. Current format changes write resolved partials; root compilation upgrade is explicit.
- `setTemplateFormatGroup(poster,format,group,value)` for resolved current-format edits (or parent can use existing normalize+deep partial path).
- `applyTemplateLookToFormats(poster,sourceFormat)` copies effective appearance into base/removes competing overrides, but image IDs remain global; preserve source title/content/assets.
- Functions must avoid circular imports: template-model may import poster-model only if pure runtime calls not module-time initialization, or keep domain helpers in poster-model exports. Communicate exact exports to parent.
