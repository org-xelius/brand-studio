# V2 shared implementation contract (approved direction; coordination)

Each agent owns only its named files. Do not edit others' files. No paid API calls. Existing model/routes/legacy scenes remain compatible.

## Poster options
`post.poster` is absent for legacy. V2 object: `{version:2, recipe:'hero'|'showcase'|'editorial', voice:'studio'|'impact'|'clean', treatment:'brand'|'light'|'dark', variation:'balanced'|'type-led'|'image-led', emphasis:string, kicker:string, scale:number[.85,1.15], heroScale:number[.8,1.2], cropX:number[0,1], cropY:number[0,1], alignment:'left'|'center'}`. Optional `formats` maps square/portrait/story/landscape to partial options (no nested formats/version). Defaults: hero,studio,brand,balanced,'','',1,1,.5,.5,left. Client may pass just version and recipe; backend normalises. `company.brandKit={voice,ink,paper}` optional hex colours. Existing company.color is accent. `campaign.artDirection` uses same normalised poster shape.

## Renderer owner
Own src/compositor.js, src/poster-renderer.js, src/fonts.js, assets/fonts/* and renderer tests/visual harness only. Preserve compose(canvas, {company,post,design,background,logo,product}) and legacy behaviour. Route post.poster.version===2 into v2 renderer; do not automatically use design.scene because editor must preview local draft. FORMATS and legacy DIRECTIONS exports stay; add RECIPES/VOICES optional. V2 returns {errors,warnings,width,height,generated,manifest}; no network model calls. Fonts self-contained; build coordinator will add .woff2:dataurl loader. At least one real licensed font per voice; renderer owner handles download/licence if possible. Missing fonts/assets/overflow block export. Renderer takes poster options as above; same bitmap used preview/export.

## Backend owner
Own model.js, model.test.js, host.test.js as needed plus new poster-model.js pure shared normalisation. Export DEFAULT_POSTER, normalizePoster(options), validatePoster(options) from poster-model.js. Keep Node crypto out of poster-model.js so client can import it. Add optional company.brandKit and campaign.artDirection; post.save preserves poster and resets statuses on actual poster edits. New posts inherit campaign artDirection or default v2, existing legacy posts unchanged unless explicit poster submitted.
New `campaign.artDirection` command takes {id,poster}, only saves look for this campaign, no image generation. New `design.snapshot` command takes {postId,assetId:'optional background asset id or empty',logoAssetId:'',productAssetId:'',format,poster,headline,body,cta}. Creates NEW immutable design version (local-only allowed without generated image). Validates company asset ownership/roles; captures full scene `{version:2,rendererVersion:2,company:clone(company),post:clone(effectivePost)}` (scene.post includes effective words, format, poster); captures asset IDs on design row; design.assetId may be empty for type-only v2 designs, legacy required. Returns metadata.id and state. Existing design.review reviews a specific version, snapshots not mutated by legacy design.save. Every snapshot initially unreviewed. Existing generation design rows add scene if snapshot.post.poster present. Prompt adds recipe-directed image placement for v2. Main aggregate version stays1 with additive optional fields and validator. Add robust tests migration/isolation/preservation/local no-job snapshots/review. Coordinator can add frontend glue without touching backend files.

## Editor owner
Own src/client.jsx and src/studio.css only. Import normalizePoster,DEFAULT_POSTER from ../poster-model.js. Preserve all existing panels. Add company typography/ink/paper fields and campaign inheritance if practical. Existing drafts default to legacy; explicit 'Create an editable v2 copy' sets poster, preserving old design history. New posts backend default v2. Add three recipe choices, voice/treatment, emphasis, kicker, scale, cropX/Y/heroScale, variation, manual linebreak textarea headline. Guided controls, local undo/reset and saving look through campaign.artDirection. Show thumbnails/format strip/local variations if practical. compose legacy signature preserved. `design.snapshot` is saved before specific review/export for v2, then review returnedid via design.review, export same rendered canvas after backend status checks. History render design.scene company/post snapshots, use design asset IDs. Background versions remain selectable (both v1generated and v2snapshot asset IDs), no regeneration for composition. Capture rendering generation/token to prevent stale export on async paints; disable export while rendering and when errors or draft unsaved. Preserve crop/selected asset choices on save/unmount. Latest historical scene loading should not mutate post unless explicit edit; communicate legacy upgrade. No automatic paid requests. Never mark stale drafts reviewed merely because another design was reviewed.
